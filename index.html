FastAPI ASR

Minimal browser microphone stream to FastAPI WebSocket to Deepgram sandbox transcript JSON.

How it works

1. Click Start Recording.

2. The browser sends audio chunks over /ws.

3. The server forwards them to Deepgram sandbox.

4. Transcript events come back as JSON.
